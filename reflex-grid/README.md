# REFLEX GRID（リフレックス・グリッド）

光ったマスを素早くタップして反射神経を競う、シンプルな1ファイルのブラウザゲームです。
HTML / CSS / JavaScript だけで動作し、ビルドや外部ライブラリは不要です。

## 遊び方

1. [`index.html`](index.html) をブラウザで開きます。
2. **スタート** ボタンを押すとゲーム開始。
3. 4×4 のグリッドのうち、光ったマスをできるだけ早くタップします。
4. 制限時間は **30秒**。タイムアップでスコアが確定します。

## ルール

- **速さがスコア** — 反応が速いほど得点が高くなります（350ms未満で3点、600ms未満で2点、それ以外は1点）。
- **コンボ** — 連続でヒットするとコンボが伸び、5コンボごとにボーナス点が加算されます。
- **ミス** — 光ったマスを逃すとコンボがリセット、関係ないマスをタップすると減点（−1）。
- **難易度上昇** — スコアが上がるほどマスが光っている時間が短くなります。
- **ベストスコア** — 自己最高記録はブラウザに保存され、次回も表示されます。

## 動作環境

モダンなブラウザ（Chrome / Safari / Firefox / Edge）。
ポインター操作に対応しているため、PC（マウス）でもスマートフォン（タッチ）でも遊べます。

## 開発

外部依存はありません。ファイルを編集して保存し、ブラウザを再読み込みするだけで反映されます。

```sh
# 例: ローカルで簡易サーバーを立てて確認する場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```
